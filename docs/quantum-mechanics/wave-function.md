# The Wave Function

In quantum mechanics, the state of an isolated system is described by its wave function, denoted by the Greek letter $\Psi$. 

The time-dependent Schrödinger equation governs how this wave function evolves over time:

$$i\hbar\frac{\partial}{\partial t}\Psi(\mathbf{r},t)=\hat{H}\Psi(\mathbf{r},t)$$

Notice how the inline math like $\hbar$ fits perfectly into the text, while the block equation stands out on its own.
